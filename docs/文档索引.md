# 文档索引

如果你只是想把项目用起来，按下面顺序看就够了。

## 1. 第一次使用

先看：

1. `README.md`
2. `快速入门指南.md`
3. `usage.md`

这三份文档会带你完成：

1. 安装依赖
2. 复制本地配置
3. 跑示例分析
4. 跑仿真模式

## 2. 准备接硬件

再看：

1. `MCU集成指南.md`
2. `mcu_reference.c`

这两份内容会帮助你：

1. 让 STM32 或其他 MCU 按正确协议发数据
2. 接收 PC 端发来的新 PID
3. 确认在线模式之前先把串口链路打通

## 3. 想理解模型为什么这样给建议

看：

1. `prompt_design.md`

它会解释：

1. 模型看到哪些信息
2. 为什么要带历史记录
3. 为什么返回必须是 JSON

## 4. 你最常用的文档其实只有三份

如果你不是来研究实现细节，平时最常回看的通常是：

1. `快速入门指南.md`
2. `usage.md`
3. `MCU集成指南.md`
