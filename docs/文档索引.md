# 文档索引

文档按使用目标组织，不需要从头到尾全部阅读。

## 第一次运行 PC 工具

1. [项目 README](../README.md)：先确认项目边界并选择路线。
2. [快速入门指南](快速入门指南.md)：完成安装和第一次本地分析。
3. [使用手册](usage.md)：查询命令、配置和 CSV 格式。

## STM32 和小车接入

1. [STM32 示例总览](../examples/README.md)：选择 F103 标准库或 G431 HAL 工程。
2. [MCU 集成指南](MCU集成指南.md)：理解初始化、文件复制、回调合并和真实 I/O 接入。
3. 对应示例目录的 README：查看芯片专用步骤和故障排查。

第一次 STM32 demo 运行不依赖 Python；需要采集和在线调参时再回到 PC 使用手册。

## 理解项目实现

- [架构说明](architecture.md)：模式、模块、协议 v2、数据质量和安全边界。
- [Prompt 设计说明](prompt_design.md)：模型输入、历史记录和结构化输出。

## 实验控制台

实验控制台的启动和当前能力见 [使用手册](usage.md#实验控制台)。
尚未完成的在线 GUI 设计记录位于 `docs/private/`，不属于普通用户必读文档。

## 最短阅读组合

- 只用 PC：README → 快速入门 → usage。
- 只跑 STM32：examples/README → 对应示例 README。
- 接入真实小车：对应示例 README → MCU 集成指南 → usage 的在线模式部分。
- 参与开发：architecture → tests → 相关源文件。
