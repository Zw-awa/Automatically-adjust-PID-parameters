# 快速入门指南

目标是在不接硬件、不配置 API key 的情况下，先证明 Python 和本地分析链路正常。

## 1. 准备 Python

需要 Python 3.10 或更高版本。在命令提示符或 PowerShell 中确认：

```bat
python --version
```

如果你下载的是 ZIP，先解压并进入项目目录；如果使用 Git：

```bat
git clone https://github.com/Zw-awa/Automatically-adjust-PID-parameters.git
cd Automatically-adjust-PID-parameters
```

Git 不是运行项目的必要条件，直接下载 ZIP 也可以。

## 2. 安装依赖

```bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

如果电脑上有多个 Python，安装和运行时应使用同一个 `python` 命令。

## 3. 第一次本地分析

```bat
python scripts/offline_analyze.py --file data/raw/example_speed_data.csv
```

成功时会看到超调量、调节时间、稳态误差、振荡次数等指标。这一步不依赖：

- API key
- 网络
- 串口
- MCU

如果这一步失败，先解决 Python、依赖或当前目录问题，不要进入在线模式。

## 4. 查看主程序入口

```bat
python main.py --help
```

应看到 `offline`、`online`、`simulate` 和 `lab` 四个子命令。

## 5. 配置 LLM

只有生成调参建议时才需要 API key。

```bat
copy config.example.json config.json
```

推荐设置环境变量 `DEEPSEEK_API_KEY`。也可以把 key 写入本地 `config.json`，
但不要把包含密钥的文件提交或发给别人。

然后运行一次仿真：

```bat
python main.py simulate --loop speed --iterations 1
```

如果出现 `401`，说明本地仿真/分析可能已经完成，但模型鉴权失败；检查 API key，
不要把它误判为 PID 分析代码故障。

## 6. 下一步

- 想查询命令和配置：看 [使用手册](usage.md)。
- 想先跑 STM32 demo：看 [STM32 示例](../examples/README.md)。
