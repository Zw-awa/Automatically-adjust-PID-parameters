# 快速入门指南

如果你只想尽快看到这个项目工作，按下面做就行。

## 1. 安装依赖

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

建议使用 Python 3.10 或更高版本。

## 2. 复制本地配置

```bash
copy config.example.json config.json
```

如果后面你要真正调用 LLM，再把本地 `config.json` 里的：

```json
"api_key": "your-deepseek-api-key"
```

替换成你自己的 key，或者直接设置环境变量 `DEEPSEEK_API_KEY`。

示例配置里的串口默认是 `COM3`。如果你要接在线模式，记得改成自己电脑上的实际串口。

## 3. 第一次不要先接硬件

先做这三步：

1. 看帮助
2. 跑本地分析
3. 跑仿真

### 看帮助

```bash
python main.py --help
```

### 跑本地分析

```bash
python scripts/offline_analyze.py --file data/raw/example_speed_data.csv
```

这一步最适合先做，因为它不依赖：

1. 网络
2. API key
3. 串口
4. MCU

### 跑仿真

```bash
python main.py simulate --loop speed --iterations 1
```

如果你还没配好有效 API key，这一步可能会在最后的 LLM 调用时报错。先看前面的分析部分是否正常输出，不要一看到 401 就误以为整个项目都坏了。

## 4. 什么时候再接在线模式

当你已经确认：

1. 本地分析能跑
2. 仿真流程能跑
3. API key 已经有效

再去做：

```bash
python scripts/monitor_serial.py --port COM3
python scripts/collect_data.py --port COM3 --loop speed --duration 20
python main.py online --port COM3 --loop speed --interval 10
```

这里的 `COM3` 只是默认示例，运行前改成你的实际串口。

## 5. 一句话建议

第一次上手时，先证明本地链路可用，再证明串口链路可用，最后再在线调参。
